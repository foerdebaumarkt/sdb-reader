# Security

## Reporting a vulnerability

Please do not open a public issue for a security problem.

Report it privately through GitHub: on this repository's **Security** tab,
choose **Report a vulnerability**. The report is visible only to the
maintainers.

If you cannot use GitHub for it, write to <service@foerde-baumarkt.de>.

Say what is affected, how to reproduce it, and what an attacker gains. You
will get an answer within a week.

## Supported versions

Fixes go into the latest release. Older releases are not patched.
