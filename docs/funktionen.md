# Funktionen auf einen Blick

Sicherheitsdatenblätter sind die Pflichtdokumente zu Produkten wie Farben,
Klebern oder Reinigern: Sie sagen, wie gefährlich ein Produkt ist und wie
man sicher damit umgeht. sdb-reader macht aus diesen PDF-Dateien
verlässliche Daten.

- Liest tausende Dateien automatisch, auch eingescannte
- Erkennt, ob eine Datei überhaupt ein deutsches Sicherheitsdatenblatt ist
- Findet Warnhinweise und Gefahrensymbole, auch wenn sie nur als Bild
  gedruckt sind
- Erkennt Produkt, Hersteller und Datum
- Erkennt veraltete Blätter, die nicht mehr gelten
- Meldet Fehler im Blatt, aber nur, wenn sie sicher sind
- Gibt unvollständige Warnhinweise nicht ungefragt weiter
- Gleiche Datei, gleiches Ergebnis, jedes Mal
- Jedes Ergebnis ist nachvollziehbar
- Liest ohne KI und ohne Cloud, auf dem eigenen Rechner
- Ergebnis für Programme oder als lesbarer Bericht, auf Deutsch oder
  Englisch
- Open Source
